# flutter-socket-chat-ui

Ready-to-use real-time chat interface with message bubbles, typing indicators, and attachments.

`#flutter` `#chat-ui` `#websockets` `#messaging` `#real-time`

## Highlights
- Modular, clean architecture
- Documented API and straightforward integration
- Tested for performance and stability

## Quick Overview
```
// Chat message entity
class ChatMessage {
  final String senderId, content;
  final DateTime timestamp;
  ChatMessage(this.senderId, this.content, this.timestamp);
}

```
